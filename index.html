Lego Destruction System

Not Creatable ModuleScript

LDS is a high-performance destruction engine for Roblox. It turns standard parts into voxel-based Lego craters upon impact.

The server handles the complex CSG math. The client handles all visual debris, particles, and sounds. This separation ensures zero server lag during explosions.

Setup & Installation

Follow these steps to install the module in your place:

  1. Create a folder named Breakable inside Workspace. Put destructible parts here.
  2. Place the Server Module inside ReplicatedStorage.
  3. Place the Client Module inside StarterPlayerScripts.
  4. Call .Start() on both modules from a Server Script and a Local Script.

Properties (Attributes)

Add these custom attributes to your parts to change how they break.

Name Value Type Summary
Unbreakable boolean If true, the part ignores all impacts. Use this for map boundaries.
Undividable boolean If true, the part shatters entirely into debris instantly instead of getting a crater.

Methods

Start

Server Client

Initializes the system. Creates required Folders and RemoteEvents automatically.

local LDS = require(game.ReplicatedStorage.LDS)
LDS.Start()

ProcessImpact

Server

Triggers an explosion at a specific location. Use this for bombs, spells, or custom weapons.

local LDS = require(game.ReplicatedStorage.LDS)

-- Define explosion settings
local params = {
    ImpactRadius = 10,
    HoleVoidRadius = 4,
    ImpactForce = 100
}

-- Fire the explosion
LDS.ProcessImpact(Vector3.new(0, 10, 0), params)
